# specdriven

Projeto de aprendizado de Spec-Driven Development: app mobile-first para rotina de cuidadores de idosos.

- `specs/constitution.md`: princípios do projeto
- `specs/roadmap.md`: ordem das features
- `specs/NNN-feature/`: spec → plan → contracts → tasks
- `backend/`: Spring Boot (a criar)
- `frontend/`: Angular (a criar)
